# Reported displacement in Bangladesh: supplementary material

Supplementary tables, figures and analysis code for a study of reported displacement in the Barishal delta and the Kurigram floodplain, Bangladesh.

## Contents

| Path | What it is |
|---|---|
| `online_resources/ESM_1.pdf` | Online Resource 1: Tables S1 to S20 and Figures S1 to S6 |
| `online_resources/ESM_2.xlsx` | Online Resource 2: all results tables as a spreadsheet |
| `online_resources/ESM_3.zip` | Online Resource 3: the R and Python code as one file |
| `code/analysis/` | The same code, to read in the browser. The `README.md` there gives the run order and matches scripts to figures |

## Data

The survey data are not in this repository. The organisation that ran the survey holds them, and they are not public. Requests go to the corresponding author and need that organisation's permission. Without the data, the scripts show the analysis but will not run.
